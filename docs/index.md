# github-board

A board for GitHub issues, Projects (v2) boards and delivery activity across one or more GitHub organisations. People sign in with GitHub, and each person sees only what GitHub lets them see.

- **One screen.** Issues, Projects boards, pull requests and releases from many repositories.
- **GitHub stays the source of truth.** A supported edit, such as a label, an assignee or a Projects field, goes back to GitHub.
- **No permission system of its own.** Every read uses the signed-in person's own GitHub token.

## Run your own

[Self-hosting](self-hosting.md) tells you how to make the GitHub App, choose who can sign in, set up the database and run the board.
